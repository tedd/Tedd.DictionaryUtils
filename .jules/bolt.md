## 2026-06-11 - Dictionary Double-Hashing Elimination
**Observation:** Operations like `ToDictionarySafe` and `ToDictionaryList` checked `ContainsKey` or `TryGetValue` prior to an `Add` for missing keys, resulting in redundant O(1) hash lookups per key.
**Strategic Action:** Introduced `.NET 8.0` specific optimization utilizing `System.Runtime.InteropServices.CollectionsMarshal.GetValueRefOrAddDefault()`. This retrieves a memory reference directly in a single pass, eliminating the double hash lookup latency.

## 2024-05-24 - `AddExtensions.GetOrAdd` Optimization
**Observation:** In standard dictionary `GetOrAdd` patterns targeting non-primitive objects, an initial `TryGetValue` lookup is typically followed by a subsequent `Add` invocation if the key does not exist. This incurs two independent `GetHashCode` computations and probing sequences against the dictionary's internal bucket arrays, resulting in an effective operation cost of O(1) * 2 lookups.
**Strategic Action:** Leverage .NET 8 `System.Runtime.InteropServices.CollectionsMarshal.GetValueRefOrAddDefault` to optimize the double lookup. This method executes a single traversal of the internal storage mechanics, generating and yielding a `ref TValue`. If `exists` evaluates to false, we initialize the value directly via the provided `valueFactory`, thereby achieving true O(1) time complexity with a single lookup and minimal stack execution overhead. Nullability warnings (`CS8714`) strictly tied to generic constraint requirements are safely disabled to preserve backward compatibility without mutating the public API.

## 2024-05-24 - Benchmark Accuracy and `GetOrAdd` Exception Integrity
**Observation:** Standard BenchmarkDotNet strategies that instantiate new reference types inside `[Benchmark]` loops obscure target metrics behind Gen0/Gen1 GC events. Also, `CollectionsMarshal.GetValueRefOrAddDefault` immediately inserts the key with `default`, meaning unhandled exceptions in subsequent factory invocations corrupt the dictionary state relative to the `TryGetValue` pattern.
**Strategic Action:** Utilize `[IterationSetup]` to perform dictionary initialization out-of-band to prevent GC pollution during loop execution. When utilizing `CollectionsMarshal.GetValueRefOrAddDefault`, always encapsulate the `valueFactory()` in a `try/catch` and execute `Remove(key)` on the generated bucket to maintain atomic integrity and prevent silent semantic regressions in fundamental data structures.
